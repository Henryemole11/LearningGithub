# Isaac Visuals Website

A responsive portfolio website built for Isaac Visuals.

## Files
- index.html — main website
- style.css — visual styling and responsive layout
- script.js — mobile menu, animations and order form
- assets/ — the portfolio images supplied for the site

## Run it
Open `index.html` in a browser.

## Put it online
Upload the entire `isaac_visuals_site` folder to a static hosting service such as GitHub Pages, Netlify or Vercel.

## Important
The order form currently prepares/copies the order message but does not send it to a business account because no Isaac Visuals WhatsApp number or email address was supplied yet. Once you have the business WhatsApp number, the form can be connected directly to it.
